# MC 全生态智能适配工程师 - Skillhub 平台描述

## 简短介绍

MC 全生态智能适配工程师是一款面向 Minecraft 模组玩家的一站式智能辅助工具，覆盖模组检索、环境搭建、Mixin 冲突扫描、崩溃修复、多语言翻译、移植可行性评估等 10 大核心功能。支持 Forge、NeoForge、Fabric、Quilt 四大主流加载器，覆盖 MC 1.16.5 至 1.21.x 全版本。

## 核心功能列表

| 编号 | 功能名称 | 说明 |
|------|----------|------|
| F1 | JAR 结构解析 | 解析模组 JAR 元数据（mcmod.info、fabric.mod.json、mods.toml），生成中文功能说明书 |
| F2 | 模组检索下载 | 从 Modrinth 搜索下载模组，支持 MC 版本和加载器类型筛选 |
| F3 | 环境引导搭建 | 智能推荐 MC 版本与加载器组合，自动检测 Java 版本与启动器路径 |
| F4 | Mixin 冲突扫描 | 检测多模组间 Mixin 注入冲突风险，定位兼容性问题 |
| F5 | 资源重打包 | 模组资源文件重打包与优化（贴图、音效、语言文件处理） |
| F6 | 存档同步 | 存档备份与恢复，支持多端同步 |
| F7 | 多语言翻译 | 模组目标语言翻译，支持中/英/日/韩/俄/西/意/希/泰/印地 10 种语言 |
| F8 | 报错修复 | 智能分析崩溃日志，识别 25+ 种错误模式并给出修复建议 |
| F8.1 | 自动修复 | 一键下载升级模组版本，自动备份替换并生成修复报告 |
| F9 | 移植可行性评估 | 模组跨版本/跨加载器迁移可行性评估，生成完整评估报告 |

## 技术亮点

- **全加载器支持**：Forge、NeoForge、Fabric、Quilt 四大加载器全覆盖
- **10 种语言支持**：内置中文、英文、日文、韩文等 10 种语言包，自动检测用户语言偏好
- **25+ 崩溃模式识别**：内置崩溃模式数据库，覆盖 OOM、光影冲突、Mixin 冲突等常见问题
- **Modrinth API 集成**：实时查询模组版本信息，无需手动查找
- **智能缓存机制**：避免重复 API 调用，提升响应速度
- **安全备份机制**：自动修复前强制备份旧版本 JAR，支持一键回滚
- **Mixin 注入分析**：深度扫描 Mixin 注入点，评估目标类兼容性
- **多平台兼容**：Windows / macOS / Linux 三端支持

## 使用方式

### 方式一：交互式菜单

下载 zip 包后解压，双击 `mc-skill-start.bat` 即可启动功能菜单，按数字选择对应功能。

### 方式二：命令行直接调用

```bash
python main.py --feature crash_analyzer --crash-log "crash-report.txt"
python main.py --feature mod_searcher --query "Create" --mc-version "1.21.1" --loader "neoforge"
python main.py --feature migration_assess --jar-path "mod.jar" --from-mc-version "1.20.1" --to-mc-version "1.21.1" --from-loader "forge" --to-loader "neoforge"
```

### 方式三：Agent AI 调用

通过 SKILL.md 声明，Agent 可自动识别并调用各功能模块，返回标准化 JSON 结果。
