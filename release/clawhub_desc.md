# MC 全生态智能适配工程师 - ClawHub 平台描述

## 简短介绍

MC 全生态智能适配工程师是一款专为 Minecraft 模组玩家和整合包作者打造的智能管理工具。通过 AI 驱动的自动化流程，让模组环境配置、崩溃排查、版本迁移等繁琐工作一键完成。支持 Forge、NeoForge、Fabric、Quilt 四大加载器，覆盖 MC 1.16.5 至 1.21.x 全版本。

## 核心功能列表

| 编号 | 功能名称 | 说明 |
|------|----------|------|
| F1 | JAR 结构解析 | 一键解析模组 JAR 文件结构，自动识别 mcmod.info / fabric.mod.json / mods.toml 元数据，输出中文功能说明 |
| F2 | 模组检索下载 | 对接 Modrinth API，按版本、加载器、分类筛选模组，支持批量搜索与下载 |
| F3 | 环境引导搭建 | 智能推荐 MC 版本与加载器最优组合，自动检测系统 Java 版本与启动器路径 |
| F4 | Mixin 冲突扫描 | 扫描 mods 目录，分析多模组 Mixin 注入冲突风险，提前发现兼容性隐患 |
| F5 | 资源重打包 | 模组资源文件重打包优化，支持贴图、音效、语言文件的批量处理 |
| F6 | 存档同步 | 游戏存档一键备份与恢复，支持本地与云端多端同步 |
| F7 | 多语言翻译 | 模组语言文件提取与翻译，支持中文、英文、日文、韩文等 10 种语言互译 |
| F8 | 报错修复 | 粘贴崩溃日志即可自动分析，识别 25+ 种错误模式，给出精准修复建议 |
| F8.1 | 自动修复 | 一键升级模组版本修复崩溃，自动备份旧版本，支持回滚 |
| F9 | 移植可行性评估 | 跨版本/跨加载器移植可行性分析，输出 API/依赖/Mixin 三维度评估报告 |

## 技术亮点

- **AI 智能分析**：基于崩溃日志的智能错误识别，覆盖内存溢出、光影冲突、Mixin 冲突等 25+ 种场景
- **全加载器兼容**：Forge、NeoForge、Fabric、Quilt 四大加载器原生支持
- **10 种语言包**：内置完整的多语言支持，覆盖全球主要语种
- **Mixin 深度分析**：扫描模组使用的所有 Mixin 注入点，评估目标环境兼容性
- **双模式运行**：支持交互式菜单和命令行两种调用方式，适配不同使用场景
- **安全优先**：所有自动操作前强制备份，支持一键回滚
- **实时 API 查询**：集成 Modrinth API，获取最新模组版本信息
- **轻量部署**：纯 Python 实现，无需额外依赖大型框架

## 使用方式

### 快速开始

1. 下载 Skill 发布包（zip 格式）
2. 解压到任意目录
3. 双击 `mc-skill-start.bat` 启动交互式菜单
4. 按菜单提示选择所需功能

### 命令行调用

```bash
# 解析模组 JAR
python main.py --feature jar_parser --jar-path "create.jar"

# 搜索并下载模组
python main.py --feature mod_searcher --query "Create" --mc-version "1.21.1" --loader "neoforge"

# 分析崩溃日志并自动修复
python main.py --feature auto_fix --crash-log "crash.txt" --fix-mods-dir "C:\...\mods"

# 评估模组移植可行性
python main.py --feature migration_assess --jar-path "mod.jar" --from-mc-version "1.20.1" --to-mc-version "1.21.1" --from-loader "forge" --to-loader "neoforge"
```

### 系统要求

- Python 3.10+
- Windows / macOS / Linux
- 网络连接（模组搜索与版本查询功能需要）
